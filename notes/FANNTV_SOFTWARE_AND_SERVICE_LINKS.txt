FANnTV - SOFTWARE DOWNLOADS AND SERVICE LINKS

CLOUD SERVER - RENT ONLINE

DigitalOcean:
https://www.digitalocean.com/products/droplets

Hetzner Cloud:
https://www.hetzner.com/cloud/

YOUR WINDOWS COMPUTER

PowerShell:
Already included with Windows. Use it for local commands and SSH connections.

Git:
https://git-scm.com/downloads
Downloads project code and later updates. You already used Git for FANnTV.

Python:
https://www.python.org/downloads/
Use Python 3.12 or newer for local testing. You already have Python installed.
Windows timezone support: py -m pip install tzdata

Visual Studio Code (optional editor):
https://code.visualstudio.com/download
Useful for viewing code and editing configuration files.

LINUX SERVER SOFTWARE

Ubuntu Server information/download:
https://ubuntu.com/download/server
For a rented VPS, select Ubuntu in the provider's dashboard. An ISO download
is only needed if you are installing the operating system yourself.

Caddy HTTPS server:
https://caddyserver.com/docs/install
Install on the Linux server using the official instructions.

Gunicorn application server:
https://docs.gunicorn.org/en/stable/install.html
Use the project's pinned requirements.txt and deployment guide on Linux.
Gunicorn is not needed to run the Windows development server.

FFmpeg (optional video conversion):
https://ffmpeg.org/download.html
Useful for preparing compatible videos. MP4 with H.264 video and AAC audio
is a practical cross-device starting format; test your target devices.

PostgreSQL (needed when the app is adapted for multiple servers):
https://www.postgresql.org/download/
A managed PostgreSQL service is an alternative to installing it yourself.
The current SQLite application needs a code/data migration before use.
